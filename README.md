# Разумист

Локальный конкурсный прототип цифрового деканата на **Go + React + SQLite**. Университет Северного Горизонта и все персонажи вымышлены; это не официальный сервис вуза.

## Публичная версия и CI/CD

Адрес сервера: https://176.98.179.224. GitHub Actions проверяет pull request; push в `main` после успешных тестов и сборки автоматически обновляет сервер. SQLite хранится отдельно от релизов. Детали, HTTPS, резервные копии и откат: [DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Быстрый запуск

Требуются Go 1.24+ и Node.js 22+ с npm или pnpm. Из корня проекта:

```sh
./scripts/dev.sh
```

Скрипт установит зависимости, соберёт React и Go и запустит локальный сервер. Откройте http://127.0.0.1:8000. Остановка — Ctrl+C. Порт можно задать: `PORT=8080 ./scripts/dev.sh`.

## Запуск вручную

```sh
npm install
npm run build
go build -o bin/razumist .
./bin/razumist --host 127.0.0.1 --port 8000 --static dist
```

Вместо npm можно использовать `corepack pnpm install` и `corepack pnpm run build`. Для разработки интерфейса используйте `npm run dev` при запущенном Go-сервере на порту 8000.

## Возможности

Вход и профиль, расписание, успеваемость и сессия, заявки со статусами, уведомления. Данные сохраняются в SQLite. Новая заявка сохраняется со статусом «Отправлена». В карточке можно явно запустить демонстрационные переходы «В работе» и «Готова»; история и уведомление сохраняются. Настоящего деканата, выдачи документов и интеграций в прототипе нет. Расписание поддерживает выбор недели; уведомления содержат объявления и конкретные дедлайны.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Для API-проверок нужен Python 3.9+, для сборки тестируемого сервера — Go в PATH. Тесты используют отдельную временную базу.

Перед публичным размещением требуются HTTPS, настройка `--public-origin https://адрес-сервиса`, проверка доступности из России и план сохранности данных. `public-origin` задаёт разрешённый Origin и Secure cookie для работы за обратным прокси; заголовкам `X-Forwarded-*` сервер автоматически не доверяет. Публичные демо-аккаунты не предназначены для настоящих персональных данных.

## Сборка отчёта

`python3 scripts/build_report.py` создаёт Word-документ и `docs/REPORT.md` из текста сборщика, `docs/report-evidence.json` и сохранённых скриншотов. Нужны Python с пакетами `python-docx` и `Pillow`. После изменения документа необходимо проверить его вёрстку; в текущем цикле все страницы проверены после рендера через LibreOffice.
