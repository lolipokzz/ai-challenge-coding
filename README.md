# Разумист

Локальный конкурсный прототип цифрового деканата на **Go + React + SQLite**. Университет Северного Горизонта и все персонажи вымышлены; это не официальный сервис вуза.

## Быстрый запуск

Требуются Go 1.24+ и Node.js 22+ с npm или pnpm. Из корня проекта:

```sh
./scripts/dev.sh
```

Скрипт установит зависимости, соберёт React и Go и запустит локальный сервер. Откройте http://127.0.0.1:8000. Остановка — Ctrl+C. Порт можно задать: `PORT=8080 ./scripts/dev.sh`.

## Запуск вручную

```sh
npm install
npm run build
go build -o bin/razumist .
./bin/razumist --host 127.0.0.1 --port 8000 --static dist
```

Вместо npm можно использовать `corepack pnpm install` и `corepack pnpm run build`. Для разработки интерфейса используйте `npm run dev` при запущенном Go-сервере на порту 8000.

## Возможности

Вход и профиль, расписание, успеваемость и сессия, заявки со статусами, уведомления. Данные сохраняются в SQLite. Новая заявка остаётся принятой до обработки сотрудником; настоящего деканата и интеграций в прототипе нет.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Для API-проверок нужен Python 3.9+, для сборки тестируемого сервера — Go в PATH. Тесты используют отдельную временную базу.
