# Приёмочные сценарии

API-проверки: 12/12 прошли. Сборка Go и React прошла. В браузере пройдены входы, расписание, оценки, заявки, уведомления и профиль; мобильная проверка — viewport 360×800, не физический телефон. Все действия — с вымышленными данными.

1. Открыть кабинет, увидеть маркировку конкурсного концепта и демонстрационные входы.
2. Войти как alina, проверить ФИО, факультет, направление, курс и группу.
3. Открыть расписание дня и недели, найти аудиторию, преподавателя и заметное изменение.
4. Открыть успеваемость, сравнить баллы, зачёты и информацию о сессии.
5. Подать заявку на справку, открыть её историю, обновить страницу: запись сохраняется.
6. Отменить свою новую заявку; убедиться, что состояние изменилось.
7. Прочитать уведомление, обновить страницу: отметка прочтения сохраняется.
8. Выйти. Открыть API без входа: доступ запрещён.
9. Войти как mark: увидеть другой профиль, оценки и список заявок.
10. Подставить идентификатор заявки alina в запрос mark: получить 404 без утечки данных.
11. Выполнить запрос изменения без CSRF-токена: получить отказ.
12. Повторить вход, навигацию, расписание, оценки и подачу заявки на ширине 360 px.
13. Пройти основные действия клавиатурой; проверить подписи полей и видимый фокус.

## Перед конкурсной отправкой (отдельный этап)

- Согласовать хостинг и развернуть HTTPS-версию.
- Проверить доступность из России без VPN.
- Обеспечить работу до 28 ноября согласно предоставленному ТЗ.
- Подготовить окончательный PDF или документ со скриншотами реальной сборки.
- Вставить ссылку на прототип и два тестовых аккаунта, предоставить исходники жюри.
- По желанию записать видео до пяти минут.

Никакое из этих будущих действий не считается выполненным в локальной сборке.
