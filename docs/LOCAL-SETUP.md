# Локальное окружение этой сборки

На компьютере автора инструменты найдены вне PATH:

- Go: `/Users/bobbyfisher/sdk/go1.27.1/bin/go`.
- Node.js: `/tmp/node-v22.16.0-darwin-arm64/bin/node`.
- npm поставляется вместе с официальным Node.js. Встроенный Node приложения не подходит для нативного Rollup из-за проверки подписи macOS.

Для этого компьютера:

```sh
export PATH="/Users/bobbyfisher/sdk/go1.27.1/bin:/tmp/node-v22.16.0-darwin-arm64/bin:$PATH"
export COREPACK_HOME=/tmp/razumist-corepack
export GOMODCACHE=/tmp/razumist-gomod
export GOCACHE=/tmp/razumist-gocache
./scripts/dev.sh
```

Каталоги `/tmp` — локальные кэши, они могут очищаться системой. При их отсутствии менеджеры повторно загрузят зависимости. На другом компьютере используйте обычные установленные Go и Node.js; эти абсолютные пути не нужны. Проект не требует платных сервисов или API-ключей.

При запуске через ограниченную среду Codex скачивание пакетов и открытие локального порта могут требовать разрешения среды. Это не деплой: сервер слушает только loopback. При обычном запуске из терминала эти ограничения среды Codex не применяются.
