# Разумист — локальный прототип
Все персональные данные вымышлены. Не деплоить и не подключать реальные сервисы.
Стек по выбору пользователя: Go + React, SQLite. Не заменять другим стеком.
Писать интерфейс и документацию на русском. Проверять ширину 360 px.
Сервер авторизует каждый запрос и фильтрует записи по текущему студенту. Не доверять student_id клиента.
Никаких секретов сервисов. Демо-пароли допустимы только для вымышленных тестовых аккаунтов, в БД только хеши.
Каждый агент фиксирует фактически сделанное и проверки; не выдумывать исследования, скриншоты или результаты.
Контракт API описан в docs/API.md. Изменения контракта согласовывать с главным агентом.
